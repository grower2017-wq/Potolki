# STATYS Потолки — сайт

Адаптивный одностраничный сайт (HTML + CSS + JS, без сборки) и `send.php` для приёма заявок.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | главная страница |
| `privacy.html` | политика обработки данных (шаблон, нужна проверка юристом) |
| `assets/js/config.js` | **все настройки**: телефон, мессенджеры, ИНН/ОГРН, цены по видам, видео с ТВ, мастера |
| `assets/js/data.js` | портфолио (проекты, фото, фильтры) и короткие видео |
| `assets/css/style.css` | стили |
| `send.php`, `send-config.sample.php` | отправка заявок на почту / в Telegram |
| `portfolio/`, `video/`, `video-tv/` | исходные фото и видео |
| `assets/img/thumbs/` | облегчённые копии фото для сетки (webp) |

## Как заполнить данные

Откройте `assets/js/config.js`. Пустое значение = блок скрыт. Основное:

- `phone`, `links.max`, `links.telegram`, `links.whatsapp`, `links.vk` — кнопки связи появятся сами;
- `legalName`, `inn`, `ogrn`, `address` — подвал и политика;
- `tvVideo.src` — путь к ролику с ТВ, например `video-tv/tv.mp4`;
- `masters` — фото мастеров;
- `reviewsWidget` — код виджета отзывов Яндекса;
- `showDevNotes: false` — перед запуском, чтобы скрыть заглушки.

## Заявки

1. Почта для заявок задана в `send-config.php` (поле `to_email`). Файл закрыт от прямого доступа через `.htaccess`.
2. Для дублирования в Telegram впишите `telegram_token` и `telegram_chat_id`. Токен не коммитьте в публичный репозиторий.
3. Нужен хостинг с PHP 7.4+ и работающей функцией `mail()`.

## Локальный просмотр

```bash
php -S 127.0.0.1:8000
```

## Выкладка на хостинг (statys-potolki.ru)

1. Распакуйте архив в корневую папку сайта (там, где должен лежать `index.html`).
2. Папка `Video-tv` с роликом ТВ уже на хостинге, её не удаляйте. Регистр букв в имени важен.
3. Откройте сайт, отправьте тестовую заявку и убедитесь, что письмо пришло на почту из `send-config.php`.
4. Когда на домене включён SSL, снимите комментарии с блока HTTPS в `.htaccess`.
